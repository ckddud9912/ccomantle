## 핵심 결론

**multilingual-e5-large 가 한국어 의미 정합성 측면에서 본질적 한계 보임**. 게임 점수가 직관과 맞지 않는 이유 = 임베딩이 의미 cluster 보다 **표면 글자 패턴** 에 강하게 반응. 다음 PR `feat/embedding-model-comparison` 에서 KoE5 / KURE 같은 한국어 특화 모델로 본질 해결 시도.

## 발견 5가지

### 1. 임베딩이 의미보다 글자 패턴에 강하게 반응 ★

**정답 "사과" top 50**:
- 1-6위: 조사 활용형 (사과와·사과는·사과가·사과의·사과를)
- 7-30위 다수가 **"-과" 끝 단어**: 제과·인과·여과·안과·내과·외과·사학과·법과·문과·교과·소아과·과학과·외과·신과·왕과·금과·양과·교과
- 의미적으로 무관한데 마지막 글자 "과" 만 같으면 cosine 높음

**정답 "배" top 20**:
- 1-13위: "배" 시작 단어 (배장·배압·배부·배란·배암·배앓이·배엽·배질·배나무)
- "차" 0.9175 — 의미 무관한데 매우 가까움 (글자 X, 그냥 일반화된 cluster?)

**원인 추정**: multilingual-e5 의 tokenizer 가 한글을 글자/subword 로 쪼개다 보니 같은 글자가 들어가면 cosine 무조건 올라감. 한국어 형태소 통합 처리 X.

### 2. 결정적 fail case — 자동차가 배보다 사과에 더 가깝다

```
사과 ↔ 배:      0.1239
사과 ↔ 자동차:  0.1668   ← 더 가까움 (?!)
```

사과·배는 둘 다 과일인데 의미 정합성 완전 깨짐. 게임에서 사용자가 "배" 시도하면 점수가 거의 0 — 직관 안 맞는 결정적 원인.

### 3. 과일 도메인 cross-check — cluster 작동 X

정답 "사과" 에서 다른 과일들의 rank·cosine:

| 과일 | rank | cosine |
|---|---:|---:|
| **배** | 3,888 | 0.1239 |
| 포도 | 737 | 0.2234 |
| 바나나 | 125 (그나마) | 0.3092 |
| 딸기 | 2,316 | 0.1556 |
| 수박 | 992 | 0.2057 |
| 망고 | 1,859 | 0.1687 |
| 레몬 | 1,574 | 0.1793 |
| 복숭아 | 1,270 | 0.1915 |

→ 과일들이 모두 top 1000 밖. 반면 "사이다" (음료) 가 9위. **도메인 cluster 완전 fail**.

### 4. 단어별로 분포 들쭉날쭉

같은 모델인데 정답에 따라 top 들의 cosine 범위가 너무 다름:

| 정답 | top 들의 cosine 패턴 |
|---|---|
| 사과·배·차·집 | top 이 0.9+ 군집 (글자 패턴 cluster) |
| **강아지·학교·사랑** | top 0.4-0.6 (의미 cluster, **정상 작동**) |

**강아지 top 20** (정상): 고양이·애완동물·애견·돼지·반려동물·거북이·반려견·동물·원숭이 — 의미 정확

**학교 top 20** (정상): 학교교육·스쿨·초등학교·교실·교육·대학·고등학교·고교·신학교·교사 — 의미 정확

**사랑 top 20** (정상): 사랑이란·사랑의·로맨스·러브·결혼·애정 — 의미 잡힘 (활용형 다수지만 의미 단어도 있음)

→ **같은 모델인데 단어 결에 따라 의미 잡히는 정도 큰 차이**. 일관성 없음.

### 5. 활용형 (조사 포함) 이 top 차지

"사과와"·"사과는"·"사과가" 같은 조사 활용형이 top 5 안. 게임에서 이런 거 점수 받는 게 의미 없음.

handoff 의 `feat/dict-cleanup-activations` 트랙으로 다룰 수 있지만, 임베딩이 같은 형태 단어를 cluster 하는 건 본질 문제 — 사전 cleanup 만으로는 부족.

### 보너스: cosine 분포 통계

정답 "사과" 에 대한 전체 60k 단어 cosine 분포:

- mean: 0.0040 (random 근접, 정상)
- std: 0.0790
- min: -0.2264, max: 1.0000
- ≥0.6: 4개
- ≥0.7: 2개

→ 분포 자체는 정상. 단 top 의 cosine 이 0.7+ 인 경우와 0.4 대인 경우가 단어마다 다른 게 문제.

| 원인 | 확률 | 검증 |
|---|---|---|
| (A) **multilingual-e5-large 모델 자체** — 한국어 형태소 처리 X, multilingual 의 본질적 한계 | ★★★★★ | KoE5/KURE (한국어 특화) 로 같은 spot-check |
| (B) **scaling 부작용** — mean center + uniform scale 이 분포 왜곡 | ★★ | raw 임베딩 (scaling 전) 로 비교 |

원인 (A) 가 압도적 — "강아지/학교/사랑" 처럼 일부 단어는 작동하지만 "사과/배" 같은 단어는 글자 패턴 cluster 되는 게 모델의 한국어 tokenizer/embedding 한계.
